## Stream handoff contract

Use [B_DETECTION_INTERFACE.md](B_DETECTION_INTERFACE.md) as the source of
truth. Each target record is:

```text
TARGET,frame_id,target_id,target_type,x,y,w,h,confidence,valid,vx,vy,velocity_valid,age,miss_count
```

- `BALL=1`, `PLAYER=2` in the stream.
- `x,y,w,h` are left-top pixel coordinates in the source frame.
- Confidence is an integer from 0 to 100.
- B reserves `target_id=0`; valid tracked IDs begin at 1.
- B emits a missing track with `valid=0` during short occlusion and restores
  the same ID when it reacquires the target.

C should continue using its existing `bc_adapter` conversion layer and must
not change the frozen `EE_GlobalTargetDescriptor` for B-only diagnostics.
