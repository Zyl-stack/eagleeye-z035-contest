# ROI 插值与精细识别的配对消融

## 适用范围

适用于验证 Nearest/Bilinear/Lanczos 或 FPGA/CPU 预处理是否影响下游识别。目的是检验收益和代价，而非预设某算法胜出。分类精度、图像质量与真实信息量分别衡量。

## 工作流

1. 冻结同一个低分辨率 source ROI、实际 applied ROI、输出尺寸和边界策略。例：96×96 clamp → 192×192，不能拿整帧 HDMI 1280×720 当 ROI 尺寸。
2. 每个 sample_id 产生全部插值版本，保留原帧/目标/场次、框大小、通道序和哈希。固定输出大小、相同归一化和模型，检查数据加载器是否偷偷再次 resize。
3. 依场次/视频划分 train/val/test。测试不同输入表示时，可用同一混合训练模型控制模型因素；如分别训练，单独作为实验因子记录，不能只比较最优结果。
4. UNKNOWN 作为推理拒识规则时，冻结 top1、top1-top2 和阈值标定集；不要在 test 上调阈值。报告闭集 accuracy、包含拒识的 operational accuracy、coverage/rejection、macro-F1、每类 recall 和混淆矩阵，并给出各指标定义。
5. 预先定义小目标或困难样本子集，报告样本数。做成对的都正确/仅 A 正确/仅 B 正确/都错误统计；明确比较的是闭集正确还是拒识后的正确，避免表格口径冲突。
6. 报告按样本或场次配对的不确定性区间；连续视频数据优先按场次分组估计。小子集和代理域只能支持限定结论。
7. 若 FPGA 输出与软件参考不同，用真实定点输出再评估。将图像质量、分类收益、延迟、资源和结果年龄一起报告；插值不会生成未采集的真实细节。

## 使用方法

复制 [assets/experiment-plan.md](assets/experiment-plan.md)，填完实验契约再运行已有推理。保留每样本预测表，确保队友可从相同 manifest 重算聚合指标。现有模型/训练脚本无需随技能重复分发。

## 失效条件

三组 ROI/模型/阈值/输出尺寸不同、同视频邻帧跨集合泄漏、只比较置信度、缺测试样本 ID、将 Pillow 结果当 FPGA 结果或将全帧缩放宣传为 ROI-only 计算，均无法证明本来提出的因果关系。

## 已验证效果与失败来源

[E08](../evidence.md#e08负消融结果同样是可复用结论)：400 配对 ROI 上闭集准确率 Nearest 49.00%、Bilinear 53.25%、Lanczos 49.75%，不支持 Lanczos 全面优于双线性。拒识后另一组指标排序不同，小目标子集只有 23 样本。代理 VOC 数据与 OV5640 桌面素材的领域差异也已观察到。

## 可直接使用的提示词

> 为这个 ROI 增强模块设计配对消融。先冻结原始样本、applied ROI、尺寸、模型和阈值，排查隐藏 resize 与场次泄漏，再计算闭集/拒识后指标、coverage、每类及预定义小目标子集结果。保留负结果，给出仅由实测支持的结论，并区分 CPU 参考与真实 FPGA 输入。
