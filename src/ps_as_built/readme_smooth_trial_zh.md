# v7 平滑 ROI 试验

v6 每次 PicoDet 推理结束才移动一次 ROI，约 1 FPS 时青框会一步一步跳。
v7 保留 v6 的人数过滤、九宫格选择、3 次推理保持和换格优势规则；
GridPolicy 只给出目标格对应的 ROI 原点，显示线程每 50ms 向最新目标移动
最多 12 像素。每条 AXI-Lite 命令由硬件确认后才提交下一条，目标变化时
直接转向最新位置，不排队执行过时位置。

测试时观察 `GRID ... target_roi=` 和连续的 `FOVEA request=... roi=...`。
相邻请求的 x/y 变化均不应超过 12；ROI 仍为 320x180，合法原点范围
是 x=0..320、y=0..180。HDMI 全局摄像头画面应一直实时变化。

这不是逐帧目标跟踪或位置预测。PicoDet 仍约 1 FPS，快速移动的人可能在
下一次检测前跑出 ROI。S2MM 0x15810 锁存错误与严格完整帧判定也未修改。
无须替换 BOOT.BIN、image.ub、RTL 或设备树。v6 包请保留以便回退。
